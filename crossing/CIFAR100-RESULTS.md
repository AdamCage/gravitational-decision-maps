# CIFAR-100. CNN, Optuna и гауссовский перенос

На официальном тесте из 10 000 изображений гауссовский перенос признаков поднял top‑1 замороженного CatBoost с **66,09% до 70,00%**. Для исходной линейной головы CNN точность выросла с **71,20% до 71,54%**. Настроенный CatBoost достиг **27,51%** на ручных признаках. Логистическая регрессия на ручных и нейросетевых признаках получила 34,88% и 71,36% соответственно.

## Данные и протокол

Нативные RGB-изображения 32×32, 100 классов, 50 000 официальных обучающих и 10 000 официальных тестовых изображений. Перестановка обучающих индексов генератором NumPy с seed 20261127 выделяет первые 5 000 строк для валидации и оставшиеся 45 000 для обучения. По валидации выбирались эпоха CNN, параметры Optuna, число деревьев для длинных прогонов и параметры потока. Числа ниже получены на полном официальном тесте. Исходный архив проверен по MD5 и SHA‑256. Независимое извлечение побайтно воспроизвело массивы. [CIFAR‑100](https://cave.cs.toronto.edu/kriz/cifar.html) · [Исходы CNN и метаданные](../crossing_results/cifar100_neural.json)

Исходную линейную голову CNN обучали совместно с энкодером. Сравнение при замороженном представлении контролирует входные признаки, сохраняя различие в обучении головы. Переобученная линейная голова дала 16 дополнительных правильных ответов, с парным \(p\approx0{,}49\). У лучшей CNN остаются трудные классы, например «выдра» с 39 правильными ответами из 100. ## CatBoost после гауссовского переноса признаков

Один раз обучили CatBoost с параметрами Optuna на исходных признаках CNN. Для каждого бюджета сравнили один и тот же замороженный ансамбль на исходных признаках и на координатах после движения к прототипам классов. Валидация включала три значения полосы и четыре ненулевых горизонта, а также \(T=0\). Для обоих бюджетов выбраны \(\beta=5{,}9471\) и \(T=1\).

При 960 деревьях получены **+3,91 п.п. top‑1** с парным 95%-м бутстрэп-интервалом **[+3,30; +4,51] п.п.** и **−2,49 п.п. top‑5**. Поток исправил 695 ошибок и изменил 304 правильных ответа на ошибочные. При 160 деревьях прирост top‑1 составил **+10,74 п.п.** с интервалом **[+9,96; +11,52] п.п.** Линейные головы сохранили более высокую точность top‑1. К нелинейной голове CatBoost не применяется аффинный сертификат из следующего раздела. [Протокол, сетка и результаты](../crossing_results/cifar100_catboost_flow.json)

Один экспоненциальный шаг Эйлера с теми же \(\beta\) и \(T\) дал 66,23% при 160 деревьях и 69,99% при 960. Преимущество RK4 над одним шагом составило +1,53 п.п. при 160 деревьях (парный 95%-й интервал [+1,19; +1,87]) и +0,01 п.п. при 960 (интервал [−0,29; +0,31]). На большем бюджете один шаг также дал 86,73% top‑5.

В обратной последовательности применили поток к центрированным логитам CatBoost с 960 деревьями. На чистом тесте top‑1 изменилась с 66,09% до 65,99%, на размытом с 19,96% до 19,98%. Оба парных интервала включают ноль. Настройки выбирались отдельно по чистой и размытой валидации. [Результаты переноса логитов](../crossing_results/cifar100_catboost_logits_flow.json)

## Гауссовский поток перед линейной головой CNN

В пространстве замороженных признаков использован один прототип на класс с одинаковыми весами, вычисленный по обучающим строкам. На валидации выбраны \(T=0{,}1\) и \(\beta=5{,}9471\). На тесте поток исправил 87 ошибок и испортил 53 правильных решения. Прирост составил **+0,34 п.п.** Парный 95%-й бутстрэповый интервал **[+0,11; +0,57] п.п.** условен на данной обученной CNN. Один шаг экспоненциального Эйлера при той же настройке дал 71,52%. У потока и новой линейной головы 205 и 187 уникальных правильных ответов соответственно (точный тест Мак-Немара \(p=0{,}39\)). У 28-эпоховой CNN лучший положительный горизонт разделил первое место на валидации с исходной головой, и предпочтение короткого горизонта выбрало \(T=0\).

При фиксированном \(T=0{,}3\) проверка достижимой оболочки с направленным округлением гарантировала сохранение метки и запаса \(10^{-4}\) исходного отступа на всём пути для **5 394 из 10 000** изображений. Глобальный критерий подтвердил 4 861 из них. На всём тесте численные конечные метки согласуются с выданными сертификатами. Удвоение разрешения RK4 сохранило все конечные метки. Дополнительная проверка DOP853 на 20 контрольных точках 39 сертифицированных путей также дала согласие. ## Парное размытие

Фиксированное гауссовское размытие 5×5 с \(\sigma=1{,}25\) пикселя приводит к снижению точности замороженной CNN с **71,20% до 22,06%**. Для восстановления признаки размытого изображения сравнивались с признаками его чистой пары. Настройки восстановления выбирались на валидационных парах по среднему квадрату ошибки признаков.

| Восстановление | MSE при сохранении метки | Top‑1 с сохранением метки | Top‑1 в свободном режиме |
|---|---:|---:|---:|
| Размытый вход | 0,4862 | 22,06% | 22,06% |
| Сдвиг к среднему обучающих признаков | 0,3469 | 22,06% | 22,07% |
| Гауссовский поток с отсечением отрезка | 0,3414 | 22,06% | 22,36% |
| Парная Ridge-калибровка с отсечением отрезка | 0,3349 | 22,06% | 39,60% |

Отсечение отрезка к выходу потока сохранило метки и снизило MSE на 29,8%. Усадка к среднему дала близкий результат. Ridge обучена на 5 000 валидационных парах и использует информацию о данном размытии. В свободном режиме она исправила 2 046 ошибок и испортила 292 правильных ответа. При обязательном сохранении метки top‑1 фиксированной головы остаётся прежним по условию задачи. MSE относится к признакам CNN. Размытие искусственное, основной результат получен с одним seed и одной архитектурой. [Результаты и настройки](../crossing_results/cifar100_flow.json)

## Воспроизведение

```powershell
uv run --frozen python -m tools.cifar100_data
uv venv --python 3.13 .research/cifar100/torch-env
uv pip install --python .research/cifar100/torch-env/Scripts/python.exe numpy==2.3.2 torch==2.11.0+cu130 --index https://download.pytorch.org/whl/cu130
.research/cifar100/torch-env/Scripts/python.exe -m tools.cifar100_neural --epochs 96 --max-seconds 530 --blur --output .research/cifar100/neural-96
uv run --script tools/cifar100_optuna.py
uv run --script tools/cifar100_boost_horizon.py
uv run --script tools/cifar100_embedding_boost.py
uv run --script tools/cifar100_embedding_budget.py
uv run --frozen python -m tools.cifar100_flow --embeddings .research/cifar100/neural-96 --output crossing_results/cifar100_flow.json --certificate-rows 10000
uv run --isolated --frozen --with catboost==1.2.10 --with optuna==5.1.0 python -m tools.cifar100_catboost_flow
uv run --isolated --frozen --with catboost==1.2.10 --with optuna==5.1.0 python -m tools.cifar100_catboost_logits_flow --model .research/cifar100-boost/neural-gdm.cbm
uv run --no-project --script tools/cifar100_plot.py
```

CUDA-прогоны использовали PyTorch 2.11.0+cu130, CatBoost 1.2.10 и Optuna 5.1.0 в раздельных окружениях. Для краткого прогона CNN заданы 28 эпох и отдельная выходная папка. GPU-обучение CatBoost допускает вариации округления. Архивы предсказаний позволяют пересчитать точности.
